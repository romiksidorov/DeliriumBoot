# Папка assets/ventoy

DeliriumBoot — это открытый инструмент разметки и записи загрузчика, но сам
бинарный образ загрузчика Ventoy (`core.img`) распространяется проектом
Ventoy (https://github.com/ventoy/Ventoy) под его собственной лицензией
(GPL-3.0) и **не включён в этот репозиторий**, чтобы не нарушать авторские
права и не раздувать размер репозитория GitHub.

## Что нужно сделать перед сборкой APK (если хотите реальную прошивку)

1. Скачайте официальный релиз Ventoy для Linux/Windows с
   https://github.com/ventoy/Ventoy/releases
2. Распакуйте архив — внутри находится файл `ventoy/ventoy_image.gz` /
   каталог `boot/` с частями загрузчика (`core.img`, `boot.img`, `ventldr` и т.д.
   в зависимости от версии).
3. Скопируйте нужный бинарный файл в эту папку и переименуйте в `core.img`.
4. (Опционально) добавьте `stage1.bin` — первые 440 байт MBR-загрузчика для
   legacy BIOS boot (используется только при выборе таблицы разделов MBR).

Если файл `core.img` отсутствует, DeliriumBoot всё равно выполнит разметку
диска и форматирование разделов, а также запишет тему и ISO-образы — но
выдаст предупреждение, что сам загрузочный код не записан, и устройство
не будет загружаться через BIOS/UEFI (однако раздел с ISO будет полностью
читаем на компьютере).

Такой подход сохраняет приложение на 100% открытым и бесплатным: сам код
DeliriumBoot никогда не скачивает ничего из интернета и не содержит скрытых
токенов — он лишь ожидает, что вы (по желанию) добавите сторонний open-source
бинарник самостоятельно, на свой выбор и ответственность.
